Geospatial Data
- in general, raster data will be saved as .tif files, which can be used in any spatial software (QGIS, R, ArcGIS, etc.)
- vector data will be saved as .gpkg files, which can be used in any spatial software (QGIS, R, ArcGIS, etc)
	- .gkpg files will contain all relevant info about each site 
	- vector data will also be saved as .kml files, which can be loaded in to Google My Maps, for easy sharing. This file format is constrained and cannot have many data columns, so will only contain the site ID and geometry

1. Quartiers_3R/
Shapefile of Trois-Rivieres neighbourhoods. 
Name indicates the name of the neighbourhood. 
geometry: polygon.

2. control_street-segments.kml
Map of the street segments sampled for control sites.
Name: unique identifier of the site 
Description: blank column generated by kml format 
geometry: point geometry indicating location 

3. mon-canopy.tif
Canopy raster produced/published by the government of Québec. Download/metadata here: https://www.donneesquebec.ca/recherche/dataset/canopee-des-six-rmr-du-quebec

4. quartiers.zip 
Map of neighbourhoods produced by the Ville de Montréal. Download/metadata here: https://donnees.montreal.ca/dataset/quartiers-sociologiques.

5. REQ_ruelles-vertes.kml
Map of green alleys produced by the Regroupement des eco-quartiers (https://www.eco-quartiers.org/ruelles-vertes). 
Name: name of the green alley 
Description: extra information on the alley
geometry: linestring of alley

6. roads.zip 
Road dataset produced by the Ville de Montréal. Download/metadata here: https://donnees.montreal.ca/dataset/voirie-actif

7. ruelles-vertes.zip
Green alley dataset produced by the Ville de Montréal. Download/metadata here: https://donnees.montreal.ca/dataset/ruelles-vertes 

8. sidewalks.zip
Sidewalk dataset produced by the Ville de Montréal. Download/metadata here: https://donnees.montreal.ca/dataset/voirie-trottoir-ilot.

9. study_street-segments.kml
Map of the street segments sampled for green alley sites.
Name: unique identifier of the site 
Description: blank column generated by kml format 
geometry: point geometry indicating location 

10. TR_ruelles.kml
The 13 green alleys present in Trois-Rivieres.
Name: name of alley as described by adjacent streets. 
Description: column generated by kml format 
geometry: linestring geometry indicating location 

11. tr_sidewalks.gpkg
Street segments used as study sites in Trois-Rivieres. 
InfrastructureID: unique identifier associated with the alley that the street segment was paired with. 
geometry: polygon of street segment.

12. tr-canopy.tif 
Canopy raster produced/published by the government of Québec. Download/metadata here: https://www.donneesquebec.ca/recherche/dataset/canopee-des-six-rmr-du-quebec

13. VSMPE_surveys_ruelles-vertes.kml
Line indicating the survey route taken with interviewees. Name is associated with anonymized ID of each interviewee.


Other Data
- this data is not geospatial. 

1. es_coding.csv
- results from our deductive interview coding. 
EcosystemService: specific ecosystem service mentioned in the interview 
Category: broader category that the ecosystem service falls in (must be one of cultural, provisioning, regulating, or supporting) 
TotalMentions: the total number of times the ecosystem service was mentioned across all interviews 
TotalPeopleMentions: the number of interviewees that mentioned the specific ecosystem service 

2. parallel-streets.csv
- specifies one of the streets that runs parallel to each alley included in the study 
InfrastructureID: unique ID assigned to the alley 
parallel_street: one of the streets that ran parallel to the alley that we sampled 

3. participant_profiles.csv
- dataset produced by collaborators at UQAM that describes the sociodemographic profile of our interviewees. 
Variable: the sociodemographic variable of interest 
Levels: the group that individual interviewees belong to re: the variable of interest 
Count: number of interviewees that fall into the specific category
